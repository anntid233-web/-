# Proxy Shop Telegram Bot

Telegram бот для продажи прокси (HTTP/HTTPS/SOCKS5) с интеграцией Proxy6.net и оплатой через ЮKassa.

## Возможности

- 🛒 Покупка прокси разных типов (HTTP/HTTPS/SOCKS5)
- 🌍 Выбор страны и количества прокси
- 💳 Оплата через ЮKassa (банковские карты, СБП, кошельки)
- 💰 Баланс пользователя с пополнением
- 🎁 Реферальная программа
- 📦 Автоматическая выдача прокси после оплаты
- ⚙️ Полноценная админ-панель
- 📊 Статистика и финансовые отчеты
- 📢 Рассылки пользователям
- 🔄 Синхронизация с Proxy6.net API

## Быстрый старт

### 1. Клонирование и настройка

```bash
cd bot
cp .env.example .env
# Отредактируйте .env с вашими настройками
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск

```bash
# Polling mode (для разработки)
python main.py

# Или через Docker
docker-compose up -d
```

## Настройка

### Обязательные переменные в `.env`:

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_IDS` | ID администраторов через запятую |
| `YOOKASSA_SHOP_ID` | ID магазина в ЮKassa |
| `YOOKASSA_SECRET_KEY` | Секретный ключ ЮKassa |
| `PROXY6_API_KEY` | API ключ от proxy6.net |

### Настройка ЮKassa

1. Создайте магазин на [yookassa.ru](https://yookassa.ru)
2. В настройках магазина добавьте вебхук: `https://your-domain.com/webhook`
3. Включите уведомления: `payment.succeeded`, `payment.canceled`
4. Добавьте `YOOKASSA_WEBHOOK_SECRET` для проверки подписи (опционально)

### Настройка Proxy6.net

1. Зарегистрируйтесь на [proxy6.net](https://proxy6.net)
2. Получите API ключ в профиле
3. Пополните баланс на proxy6.net для покупки прокси

## Админ-панель

Доступна администраторам (ID в `ADMIN_IDS`) через кнопку "⚙️ Админ-панель" в главном меню.

### Функции админки:

- 📊 **Статистика** — пользователи, заказы, прокси, финансы
- 👥 **Пользователи** — поиск, просмотр, изменение баланса, бан
- 📦 **Прокси** — просмотр всех прокси, ручное добавление, синхронизация с API
- 📋 **Заказы** — управление заказами, ручное выполнение, возвраты
- 💰 **Финансы** — отчеты за день/неделю/месяц
- 📢 **Рассылка** — HTML-сообщения всем пользователям
- ⚙️ **Настройки** — мин. пополнение, реф. бонус, наценка, тех. работы

## Режимы работы

### Polling (разработка)
По умолчанию. Не требует публичного домена.

### Webhook (продакшн)
Требует:
- Публичный домен с HTTPS
- Открытый порт (по умолчанию 8080)
- Настроенный `WEBHOOK_HOST` в `.env`

```bash
# В .env:
WEBHOOK_HOST=your-domain.com
WEBHOOK_PORT=8080

# Запуск:
docker-compose up -d
```

## База данных

По умолчанию используется SQLite (`bot.db`). Для продакшена рекомендуется PostgreSQL:

```env
DATABASE_URL=postgresql+asyncpg://user:pass@host/db
```
